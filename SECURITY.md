# Security policy

Design to Ship is currently an instruction-first package with no runtime network service. Treat third-party skills, scripts, plugins, design files, URLs, and MCP connections as untrusted until reviewed.

## Report a vulnerability

Do not open a public issue for a vulnerability involving credentials, arbitrary command execution, unsafe file access, or an exploitable workflow instruction. Use GitHub's private vulnerability reporting for this repository.

Include the affected version, reproduction steps, likely impact, and any suggested mitigation. Do not include live secrets or personal data.

## Supported versions

Security fixes apply to the latest tagged release. The project will document broader support when it reaches 1.0.
