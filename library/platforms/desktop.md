# Desktop platform guidance

Design for precision input, keyboard efficiency, resize behavior, multiple windows, dense information, menus, shortcuts, drag and drop, and persistent work. Do not stretch a mobile layout across a large canvas. Preserve discoverability alongside expert acceleration.

Verify minimum and maximum useful window sizes, keyboard-only operation, shortcut conflicts, mouse and trackpad behavior, high-density content, multi-monitor scaling, offline or file errors, and safe recovery from window closure.
