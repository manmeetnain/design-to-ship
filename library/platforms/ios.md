# iOS platform guidance

Respect platform navigation expectations, safe areas, Dynamic Type, VoiceOver, reduced motion, increased contrast, localization, and system permission timing. Prefer native controls when their behavior satisfies the product need. Make destructive actions, background activity, offline behavior, and cross-device state explicit.

Verify on the smallest supported layout, a large Dynamic Type size, both orientations when supported, VoiceOver focus order, keyboard behavior where applicable, and interrupted network or permission states.
