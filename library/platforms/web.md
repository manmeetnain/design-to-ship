# Web platform guidance

Use semantic HTML as the default interaction substrate. Preserve URL, history, browser navigation, zoom, reflow, text selection, autofill, keyboard operation, and assistive-technology semantics. Design loading around network uncertainty and preserve user input during recoverable failures.

Verify representative viewport widths based on the product's layout transitions rather than device-name presets. Include keyboard-only completion, 200% zoom, increased text spacing, reduced motion, slow network, and long localized content where relevant.
