# React and Next.js implementation pack

Preserve server/client boundaries, route semantics, progressive enhancement, and accessible HTML. Prefer existing components and tokens over page-local abstractions. Keep data fetching, mutation state, errors, and optimistic behavior explicit. Avoid turning every component into a client component to support a small interaction.

Map requirements to routes and components, states to test cases, and semantic tokens to CSS variables or the repository's established token layer. Verify hydration, keyboard behavior, slow data, route transitions, errors, narrow layouts, and reduced motion.
