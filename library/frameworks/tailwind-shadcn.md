# Tailwind CSS and shadcn/ui implementation pack

Treat utilities and registry components as implementation tools, not the design system itself. Establish semantic tokens and component contracts before composing classes. Extend existing shadcn/ui primitives rather than copying near-identical variants into pages.

Avoid arbitrary values without a documented product need, unreadable class duplication, and default component styling presented as a distinctive brand. Verify focus states, variants, dark mode, long content, and responsive composition.
