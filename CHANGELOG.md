# Changelog

All notable changes are documented here. The project follows semantic versioning after 1.0.0.

- Stabilize the vendor-neutral Design to Ship specification.
- Add public contract benchmark and governance.
- Document interoperability, versioning, migrations, and releases.
- Promote the complete Intent → Structure → System → Build → Proof workflow.

## 0.1.0 — 2026-09-02
